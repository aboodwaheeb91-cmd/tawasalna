## PR 8.5a — الحذف الناعم للحساب + استعادة من الأدمن + «حساب محذوف» (F27) — 2026-10-31

- `DELETE /admin/user/{id}` صار **حذف ناعم** (`{reason?}`): ما في `DELETE FROM users` بأي مسار بعد هالمهمة. أعمدة جديدة `users.deleted_at` / `deleted_by` / `deleted_kind` (`admin` | `self`) / `deleted_reason` (للأدمن بس) — migration حرجة `account_deletion` + `docs/migrations/8.5a_soft_delete.sql` للإنتاج.
- الكاتب الوحيد `account_deletion.py` (`soft_delete` / `restore` / `apply_effects`). الحذف: `session_version + 1` → 401 بكل طلب فوراً + WS 4008؛ الدخول بكلمة سر صح → 401 `account_deleted` «الحساب غير متاح» (الغلط = الرد العادي)؛ استرجاع كلمة السر والتسجيل بإيميله = نفس الرد العادي وما في إيميل.
- قاعدة الظهور نفسها (`bs.active_sql` / `visible_sql`) بتخفي المحذوف متل المعلّق: الملف · المنشورات · التعليقات · الوظائف · البحث. `followers_count` (+ `following_count` وعدّاد الشركة) = صفوف المتابعة من حسابات فعّالة (`bs.active_sql` — مش معلّق ومش محذوف)، ونفس الرقم لكل المشاهدين: الحظر بيخفي من القائمة بس، مش من العدّاد (قاعدة وحدة مع قرار 5.4g).
- المحادثات وطلبات التوظيف والـ pipeline والمواعيد بتضل عند الطرف التاني باسم «حساب محذوف» (twT `account.deleted`) — بدون صورة / رابط ملف / `tw_id` / إيميل / هاتف بالرد نفسه؛ الإرسال للمحذوف مرفوض (404).
- حذف شركة: وظائفها المفتوحة بتتسكّر + إشعار داخلي واحد لكل متقدم قيد المراجعة (بدون سبب) + المقابلات القادمة بتنلغى عبر `cancel_appointment` (للفرد كمان). ما بينبعت شي للحساب المحذوف. حذف مرتين = إشعار واحد.
- جديد: `POST /admin/user/{id}/restore` `{reason}` (إجباري) — المحتوى بيرجع، التوكنات القديمة بتضل 401، الوظائف بتضل مسكّرة. الاتنين `users.delete` + التحقق الإضافي (428).
- الأدمن: `admin-view` — حذف بسبب اختياري + كتابة «حذف» · شارة «محذوف» + التاريخ + النوع + السبب · «استعادة الحساب» · قائمة المستخدمين بتعرض الشارة (`GET /admin/users` → `deleted_at`) · هدف البلاغ لحساب محذوف = «حساب محذوف» بدون رابط ولا زر حذف.
- حد جديد `LIMITS["account_reason_max"]` (500). `DELETE /auth/user/{id}/delete` لسا 403 (8.5d). قوانين: `docs/rules/account-deletion.md` · اختبار `tests/test_account_deletion_85a.py` (SECURITY_TESTS).

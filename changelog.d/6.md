## PR 6 — حد عام للطلبات على المسارات العامة (HTTP) — 2026-10-24

- جديد: `_public_rate` (dependency) على كل route بيشتغل للزائر — 20 مسار JSON (منها `GET /news/banner` · `/jobs` · `/profile/{id}` · `/company/profile/{id}` …) + `/u/{tw_id}` + المسارات القديمة `?id=`. سلة وحدة لكل IP (`public_ip:{get_client_ip}`) على `_rate_store` نفسه.
- القيمة 240 طلب / 60 ث من `tw_settings.rate("public_ip")` — قابلة للتعديل من الأدمن (`public_ip_hits` 60–2 000 · `public_ip_window_s` 10–600، مجموعة `sec_public`، أمني: تأكيد مكتوب + سجل أمني).
- التجاوز → 429 + `Retry-After`: مسارات API `{ok:false, error:{code:"rate_limited"}}` · مسارات HTML صفحة صغيرة بنص twT `limits.rate_limited`. الطلب المرفوض ما بينحسب.
- `_rate_hit_retry` = خطوة `_rate_hit` المقفولة نفسها + ثواني الانتظار (`_rate_hit` صار غلاف إلها، سلوكه ما تغيّر).
- مستثنى (`PUBLIC_RATE_EXEMPT` مع سبب): الملفات والصفحات الثابتة · `/u` · `/health` · `/ping` · `/log/error` · مسارات `_RATE_LIMITED_PATHS` — حدودها ما تكررت.
- تست بنية بيمرق على `app.routes`: route للزائر بدون `_public_rate` ولا استثناء → الـ CI بيفشل. الـ WebSocket خارج المهمة (AUD-P2-19).
- توثيق: ARCHITECTURE §80 · SYSTEMS_INDEX §54o · CLAUDE.md (Input Limits القاعدة 4) · `docs/rules/settings.md`.

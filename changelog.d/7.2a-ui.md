## PR 7.2a-ui — نظام الدعم: الواجهة (صفحة الدعم العامة · صفحة المتابعة · الأدمن · الروابط) — 2026-10-24

- `/support` صارت عامة: الأسئلة الشائعة لكل الزوار من `GET /support/meta` (24 سؤال، النصوص `support.faq.*`) + بحث محلي بالسؤال والجواب · «لم تُحلّ مشكلتي» تحت كل جواب بيفتح النموذج بالتصنيف و `faq_id` معبّيين.
- المسجّل: أي تصنيف + الحقول الاختيارية من meta (قوائم · التاريخ بقوائم يوم / شهر / سنة) + طلباته بحالات (وصلنا طلبك · قيد المراجعة · نحتاج معلومات منك · تم الحل) + الرد + «تم الحل». الزائر: «الدخول والحساب» بس بمسار OTP → «أرسلنا رابط المتابعة إلى بريدك» + رقم H (الرابط ما بينعرض) · «فقدت رابط المتابعة؟» → نفس الرسالة العامة دائماً.
- `/support/track`: الرمز من الـ hash بينمسح فوراً من الشريط (`history.replaceState`) وبينبعت بالـ POST بس · الحالة والرسائل والرد و«تم الحل» · 404 → رسالة عامة + «إعادة إرسال الرابط» · meta noindex + no-referrer.
- الأدمن: فلاتر زائر / مسجّل + ترتيب + بحث برقم H أو الإيميل · عرض المعلومات الإضافية والسؤال الشائع والتصنيف القديم · الرد بزرّين («نحتاج معلومات» / «تم الحل») · تغيير التصنيف بتأكيد · عدّاد الطلبات الجديدة بالقائمة.
- روابط «الدعم»: القائمة ☰ للمسجّل · «تواصل مع الدعم» بالإعدادات · أسفل الصفحة الرئيسية للزوار. تسميات التصنيفات صارت متل نصوص الأسئلة («الدخول والحساب» · «بلاغ أو شكوى» · «استفسار أو اقتراح»…).

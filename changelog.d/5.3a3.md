## PR 5.3a3 — لوحة الأدمن: جدول المستخدمين والشركات + تصدير CSV + صفحات النشاط — 2026-10-15

- **endpoint جديد `GET /admin/users`** (`check_admin`): بحث (اسم / إيميل / tw_id) · فلتر النوع (`emp` / `co` / `edu`) · فلتر التوثيق (موثّق / معلّق التوثيق / غير موثّق) · ترتيب بتاريخ التسجيل · صفحات من السيرفر (`limit` ≤ 100). الحقول: id · tw_id · الاسم · الصورة (`profiles` وإلا لوغو `company_profiles`) · النوع · الإيميل · حالة التوثيق · تاريخ التسجيل — بس. قيمة غلط → 422.
- **انحذف `GET /auth/users`** (كان بيرجّع كل الحسابات مرة وحدة وما حدا بيستعمله غير الأدمن) — الجدول والبحث الموحّد صاروا على `/admin/users`.
- **الجدول بقسمي «المستخدمون» و«الشركات»** (نفس الـ view، الشركات بفلتر ثابت): ديسكتوب جدول (صورة + اسم · النوع · الإيميل · التوثيق · تاريخ التسجيل · عرض / تعديل / حذف) · صندوق ضيق صفوف مضغوطة بدون سكرول أفقي على 390px · البحث بينبعت بعد ما يوقف الكتابة · أرقام صفحات (1 … 4 5 6 … 20).
- إجراءات الصف صارت **عرض / تعديل / حذف** — «رسالة» و«توثيق» صاروا بصفحة الحساب (`admin-view`) بس؛ قوالب الرسائل الجاهزة (ترحيب / توثيق / تحذير / مقابلة) انحذفت مع نافذتها ومفاتيحها. «تعديل» بيفتح `admin-view?id=N#edit` على كرت الحقول.
- **تصدير CSV** (`GET /admin/users/export` — نفس الفلاتر، نفس الأعمدة بدون الصورة، UTF-8 + BOM، حماية من formula injection) بتأكيد قبل التحميل عبر `TwAdminShell.run` (خيار جديد `as: 'blob'`)، وبينسجّل بالسجل الأمني (`AUDIT_READ_ROUTES` — أول قراءة بتنسجّل).
- البحث الموحّد بالشريط العلوي: المستخدمين / الشركات من السيرفر بعد توقف الكتابة (بدل تحميل كل الحسابات).
- **نظام مشترك صغير `twFormatNumber(n)`** بـ `tw_shared.js` (فواصل آلاف، أرقام عادية) — كروت الرئيسية + ملخص الرسومات + الجدول (SYSTEMS_INDEX §59a).
- **النشاط المباشر:** الرئيسية بتعرض آخر 8 بس + «عرض الكل» → قسم «النشاط» جديد بالقائمة بصفحات من `GET /admin/activity?page=&limit=` (صار رده `{items, total, page, limit}`). السجل الأمني صار بنفس أرقام الصفحات.

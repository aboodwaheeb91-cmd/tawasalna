## PR 4.2 — الإعدادات الأمنية والسعات بنظام الإعدادات الموحّد — 2026-10-23
- `tw_settings.py`: 22 إعداد أمني جديد بالـ registry نفسه (`security=True`، مجموعات `sec_*`): أقفال الدخول · OTP · pwreset · `mem_store_*` · كاش دولة الـ IP · أحجام الصفحات · نافذة `view_count` / `report_repeat`. `password_max_bytes` ما انضاف (حد bcrypt ثابت).
- كل قارئ بيمرّ من `tw_settings.limit` / `rate` وقت الاستعمال (التعديل بيسري فوراً): `_login_locked` · `auth.otp_ttl_minutes()` / `otp_max_attempts()` · `_rate_ok("pwreset_ip" / "pwreset_email")` · مخزن الحدود · كاش الـ IP · صفحات التعليقات / الإشارة / المحظورين. انحذفت الثوابت `_OTP_TTL_MINUTES` · `_OTP_MAX_ATTEMPTS` · `_PWRESET_*` (القيم الافتراضية نفسها، صارت بـ `tw_limits`).
- السجل: إعداد أمني → `action` = `admin_settings_update_security` / `admin_settings_reset_security` (لكل نتيجة) — بدون عمود ولا migration.
- الشاشة: قسم أمني منفصل بتحذير + شارة «أمني» + تأكيد بكلمة مكتوبة قبل الحفظ / الإرجاع. 403 = رسالة «ما عندك صلاحية» بالصفحة والجلسة بتضل · 401 = رجوع للدخول (`permissionAware` بـ `TwAdminSession.fetch` / `TwAdminShell.run`).
- اختبارات: `tests/test_admin_settings_security.py` (جديد) · `tests/test_admin_shell_runtime.js` (H) · تحويل `test_admin_settings` / `test_input_limits_50h2` / `test_rate_store_54d` / `test_password_reset_email` / `test_otp_rate_limit_security` لقراءة القيم من `tw_settings`.

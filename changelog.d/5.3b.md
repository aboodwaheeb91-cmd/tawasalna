## PR 5.3b — admin-view.html على الـ Admin Shell + تأكيدات الإجراءات الكبيرة + حذف /tw-ctrl-login — 2026-10-15

- `admin-view.html` (تعديل المستخدم) تحوّلت بالكامل: Page Shell أدمن · الهيدر + القائمة الموحّدة (المستخدمون معلَّم — الصفحة مش بالقائمة) · معالجة 401 من الـ shell · كروت `TwAdminShell.card` مع ⓘ · ألوان 130 → 0 · emoji → DS-ICON · كل النصوص `twT` (`admin.view.*`) · النوافذ DS-OVL · المنطق بـ `static/admin-view/admin-view.js` · `page_audit` = 0 بكل الأرقام.
- Admin Shell: `TwAdminShell.start({outside: true, current})` لصفحة برّا مسار اللوحة — جذر اللوحة من التاب نفسه؛ تاب ما فتح اللوحة → رسالة بدون تحويل.
- تأكيدات (كلها عبر `TwAdminShell.run`، النتيجة بتنفحص قبل «تم»): تغيير نوع الحساب = تحذير بيشرح شو بيتغيّر + زر التأكيد مطفّي لحد ما تنكتب «تغيير» · تغيير كلمة السر = تحذير (خروج من كل الأجهزة + إلغاء روابط الإيميل المعلّقة) · حذف خبرة / شهادة / دورة · تعديل البروفايل · إلغاء التوثيق · الرسالة للمستخدم = تأكيد بيشرح · حذف الحساب = كتابة «حذف».
- حذف `POST /tw-ctrl-login` القديم (route + قائمة الـ rate limit + التوثيق) — الدخول بس عبر `<مسار اللوحة>/login`؛ القديم → 404.
- تستات: `tests/test_admin_shell_runtime.js` (E) · `tests/test_admin_session_security.py` (401 / 429 / 404) · فحص نص الـ rate limit بـ `test_admin_safe_rendering.py` صار سلوكي.

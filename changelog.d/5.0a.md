## PR 5.0a — إصلاح عاجل: تسجيل الحسابات الشخصية + رسالة «البريد مسجل مسبقاً» — 2026-10-14

- السبب الجذري: `create_user` بيعمل `INSERT INTO profiles … ON CONFLICT (user_id)` وجدول `profiles` بالإنتاج انعمل قبل `UNIQUE(user_id)` → خطأ Postgres فيه كلمة "unique" → الكود حوّله لـ «البريد الإلكتروني مسجل مسبقاً» (409).
- migration حرجة جديدة `profiles_user_unique` (`auth._migrate_profiles_user_unique`): حذف المكرر (بيضل الأقدم) + `CREATE UNIQUE INDEX IF NOT EXISTS profiles_user_id_key` — idempotent مع القيد الموجود بالإنتاج. `_ensure_user_unique_index` بيقبل `col=None` (UNIQUE على `user_id` لحاله).
- `create_user`: «البريد مسجل مسبقاً» (`EmailTakenError` → 409) بس لـ SQLSTATE `23505` على `users_email_key` (`_is_email_taken_error` من حقول الخطأ، مش النص). أي خطأ تاني → log + `_server_error("register")` → 500.
- اختبار `tests/test_register_profiles_unique.py` (DB) · SYSTEMS_INDEX §54f · ARCHITECTURE (create_user).

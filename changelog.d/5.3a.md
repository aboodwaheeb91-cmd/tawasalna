## PR 5.3a — هيكل الأدمن الموحّد (Admin Shell) + تحويل admin.html — 2026-10-15

- نظام جديد **Admin Shell** (SYSTEMS_INDEX §25a · `docs/rules/admin-shell.md`): هيدر + قائمة وحدة لكل صفحات الأدمن (موبايل أولاً) من registry واحد `static/shared/admin-sections.js` (مفتاح · أيقونة DS-ICON · مفتاح twT · مسار نسبي) · شارات البلاغات الجديدة / التوثيق قيد المراجعة · انتهاء الجلسة (401 / 403 / انتهاء الساعة) → صفحة الدخول برسالة «انتهت جلسة الإدارة» من مكان واحد · `TwAdminShell.run` = طريق الكتابة الوحيد (تأكيد قبل أي طلب) · `TwAdminShell.card` = كرت مع ⓘ.
- `admin.html` تحوّلت بالكامل: Page Shell أدمن · الأقسام (نظرة عامة · المستخدمون · الوظائف · البلاغات · توثيق الهوية · الأخطاء · الشعار والصيانة) من القائمة · ألوان 110 → 0 · emoji → DS-ICON · كل النصوص `twT` · نافذة الرسالة ومستندات التوثيق → `twModal` · المنطق بـ `static/admin/admin.js`.
- تأكيدات: حذف حساب / وظيفة وترحيل الصور → تأكيد تحذيري وزر التأكيد مطفّي لحد ما تنكتب «حذف» / «ترحيل» · رفض توثيق (تحذيري) · قبول توثيق · حل بلاغ · توثيق حساب · استبدال الشعار → `twConfirm` بيشرح شو رح يصير.
- `admin-email.html` انضمت للـ shell والقائمة (انشال رابط «العودة» ورسالة «سجّل الدخول» — الـ shell بيحوّل للدخول) وكروتها صارت `TwAdminShell.card`.
- `admin-view.html`: زر «رجوع للإدارة» بيرجع لقائمة المستخدمين (`TwAdminSession.panelHref()`) — باقي الصفحة لمهمة 5.3b.
- ما في `tw-ctrl-` بأي ملف بيوصل للمتصفح: الدخول بيروح لـ `<جذر اللوحة>/login` (نفس الـ handler، rate limited)؛ `/tw-ctrl-login` القديم باقي للتوافق.
- إصلاح: قبول / رفض التوثيق كانوا بيبعتوا بدون body → 422 دايماً؛ هلق `{note: ""}` (نفس الـ endpoint). الإجراءات كانت بتطلّع «تم» حتى لو فشل الطلب؛ هلق بتفحص النتيجة.
- اختبار: `node tests/test_admin_shell_runtime.js` (جديد) · فحوص نصية بـ `test_admin_pages_min.py` / `test_page_shell.py` / `test_page_shell_security.py` (صار يمنع `tw-ctrl-` كلياً) اتحدّثت · `page_audit` baseline.

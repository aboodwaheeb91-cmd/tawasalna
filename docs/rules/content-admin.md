# Content Screens — النصوص · الألوان · الأخبار (phase 5a backend · 5b screens + banner)

> Spec: `docs/SYSTEMS_INDEX.md §25h` · `ARCHITECTURE.md §79` / `§79b` · tests `python -m pytest tests/test_content_admin_5a.py -q` · `node tests/test_admin_shell_runtime.js` (I) · `node tests/test_news_banner_runtime.js`

1. **الصلاحية `content.edit`** (`server.CONTENT_PERM`) على كل قراءة وكتابة بـ `/admin/strings` · `/admin/theme/colors` · `/admin/news` عبر `check_admin(request, CONTENT_PERM)` — نفس نمط `settings.edit`: بدون توكن / توكن غلط → 401 · أدمن بدون الصلاحية → 403. الأدمن الرئيسي `perms: ["*"]`.
2. **السجل:** صف `admin_audit_middleware` الواحد (العملية · الفاعل · النتيجة) + الهدف عبر `request.state.audit_target`: `keys=…` (النصوص) · `tokens=…` (الألوان) · `news_id=…` (الأخبار). ❌ تخزين النص / اللون / محتوى الخبر بالسجل.
3. **الألوان:** الـ PUT بيقبل `theme_tokens.EDITABLE` بس (`--color-brand-primary` · `--color-brand-accent`) وقيمة `#RRGGBB` بس → غير هيك 400. الـ overrides القديمة لتوكنات تانية بتضل محفوظة وبيطبّقها `/theme.css`. ❌ حذفها عند الحفظ.
4. **الأخبار:** `starts_at` / `ends_at` (`TIMESTAMPTZ NULL`، `ends_at > starts_at` وإلا 400). «نشط» = `server.NEWS_ACTIVE_SQL` بس — الفيد و `/news/banner`. ❌ شرط «نشط» تاني.
5. **`GET /news/banner`** عام بدون دخول: أحدث خبر نشط أو `null`، حقول `id` · `title` · `summary` · `source_url` بس (رابط مش http/https → `null`). ❌ حقول داخلية · ❌ مسودة / مؤرشف / مجدول / منتهي.
6. **شاشة المحتوى (5b):** `admin-content.html` (اللوحة + `/content`، سطر `content` بـ `TW_ADMIN_SECTIONS`) + `static/admin-content/admin-content.js` على الـ Admin Shell — 3 تبويبات (نصوص · ألوان · أخبار). 403 → رسالة «ما عندك صلاحية» بالصفحة والجلسة بتضل (`permissionAware` متل الإعدادات) · 401 → الدخول. كل كتابة عبر `TwAdminShell.run` بتأكيد. ❌ `TwAdminSession.fetch` مباشر لكتابة.
   - **النصوص:** المفاتيح الموجودة بس (ما في إضافة) · الحفظ = كل الـ overrides + هالمفتاح · «رجّع للافتراضي» = نفس الخريطة بدون المفتاح.
   - **الألوان:** picker + `#RRGGBB` · معاينة (زر · رابط · شارة) على متغيّر محلي `--pv` · التباين WCAG مقابل `--color-surface-page` ونص الزر: أقل من 4.5 → تحذير · أقل من 3 → الحفظ ممنوع (بالصفحة — UX؛ السيرفر بيفحص الشكل بس) · الافتراضي من `GET` `defaults` (`theme_tokens.editable_defaults()`). ❌ لون مكتوب بالصفحة.
   - **الأخبار:** «نشط الآن» = `active_now` من السيرفر (`NEWS_ACTIVE_SQL` بالاستعلام) — ❌ حساب «نشط» بالصفحة · البداية / النهاية عبر `twDateTimeField` (DS-DATE — توقيت المتصفح → `toISOString()` UTC؛ فاضي = بدون حد، نص تعبئة = مرفوض) · الأرشفة = PUT بكل الحقول + `archived` (القائمة فيها `body`) · الحذف = كلمة مكتوبة.
7. **شريط الإعلان (5b):** `static/shared/tw-news-banner.js` بس (أعلى `/` و `/home`، host `[data-tw-news-banner]`) من `GET /news/banner` عبر `twApi` بدون دخول: `null` أو فشل → ما بيظهر شي وبدون console · كل النص `textContent` · الرابط عبر `twSafeLinkUrl` + `target=_blank` + `rel="noopener noreferrer"` · الإغلاق بيحفظ id الخبر بـ `localStorage` `tw_news_banner_closed` (try/catch) وما بيرجع يظهر لنفس الخبر. ❌ `innerHTML` لنص الخبر · ❌ شريط تاني بصفحة.

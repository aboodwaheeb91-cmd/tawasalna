# قاموس التسميات — تواصلنا (GLOSSARY)

> **المصدر الوحيد للكلمات المعتمدة بالواجهة** (PR 3.6 · SYSTEMS_INDEX §59 · قرارات زعتر).
> كل نص بالواجهة مفتاح بـ `twT` (`tw_strings.json`) — والنص نفسه لازم يستعمل الكلمة المعتمدة هون.
> الكود الداخلي (`emp` / `co` / `edu` · أسماء الجداول والـ endpoints) **ما بيتغيّر** — هاد القاموس للنص اللي بيشوفه المستخدم بس.
> آخر تحديث: 2026-10-07 · PR 3.6 · التاريخ بـ [`docs/CHANGELOG.md`](CHANGELOG.md)

## القاموس

عمود «ممنوع» بيقراه `test_strings_system.py` (القسم F — تقرير بيعدّ المخالفات بالموقع): كل كلمة بين `` ` `` = نمط بحث (regex). نمط عليه `(مراجعة)` = الكلمة ممكن تكون صحيحة بسياق تاني — العدّ للمراجعة اليدوية بالمرحلة 4، مش خطأ أكيد.

| المفهوم | الكلمة المعتمدة | مفتاح twT | ممنوع |
|---------|----------------|-----------|-------|
| إعلان عمل تنشره شركة | **وظيفة** / **الوظائف** · «نشر وظيفة» | `jobs.title` · `jobs.post` | `فرص` (بيشمل فرصة / الفرص) |
| نوع حساب الشخص (`emp`) | **حساب شخصي** | `account.type.emp` | `حساب موظف` · `موظف` (مراجعة) |
| نوع حساب الشركة (`co`) | **حساب شركة** | `account.type.co` | `حساب منشأة` |
| نوع حساب الجهة التعليمية (`edu`) | **حساب جهة تعليمية** | `account.type.edu` | `حساب مؤسسة تعليمية` · `حساب جامعة` |
| اللي قدّموا على وظيفة (`job_applications`) | **المتقدمون** | `people.applicants` | `المتقدمين للفرصة` |
| اللي بمراحل التوظيف (`job_pipeline_entries`) | **المرشحون** | `people.candidates` | `المرشحين` (مراجعة) · `المرشحون` (مراجعة) |
| الأشخاص المحفوظين عند الشركة | **بنك المواهب** | `people.talent_bank` | `المرشحين المحفوظين` · `المحفوظين` (مراجعة) |

> «المرشحين / المرشحون» صحيحة **بس** لمعنى مراحل التوظيف. استعمالها لمعنى «اللي قدّموا» أو «المحفوظين» مخالفة — لهيك عليها (مراجعة).

## القواعد

1. كلمة جديدة لمفهوم موجود → ممنوع. استعمل الكلمة المعتمدة أو اقترح تعديل القاموس أولاً.
2. مفهوم جديد بالواجهة → سطر جديد هون + مفتاح بـ `tw_strings.json` بنفس الـ PR.
3. الأماكن المحوّلة لـ `twT` (الهيدر · الشريط السفلي · قائمة الهيدر · `appointments.html`) لازم تضل بدون أي كلمة ممنوعة — الاختبار بيفشل. الباقي تقرير عدّ بس لحد ما تتحوّل الصفحة بالمرحلة 4.
